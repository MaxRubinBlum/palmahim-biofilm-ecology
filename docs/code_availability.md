# Suggested Code availability statement

Custom scripts used for community statistics, taxonomic-functional beta-diversity analyses, functional redundancy calculations, abundance-weighted taxon-trait analyses, C1 network construction and figure preparation are publicly available at:

https://github.com/MaxRubinBlum/palmahim-biofilm-ecology

The repository includes a simulated reviewer demo, environment specifications, reproducibility documentation and automated smoke tests. The version corresponding to the accepted manuscript will be archived in a persistent repository (for example Zenodo), and the resulting DOI will be cited in the final article.
