# Suggested phylogenomics Methods text

We used the bacterial bac120 phylogeny generated by GTDB-Tk to represent relationships among the recovered bacterial MAGs (Supplementary Fig. 2) and extracted the Methylococcales subtree from this phylogeny for the focused analysis shown in Fig. 5. For lineage-specific phylogenies of *Methyloprofundus*, QPIN01/MMG2 and CAJXQU01 (Supplementary Figs. 4–6), we used GToTree v1.7.10 with the Gammaproteobacteria HMM set comprising 172 conserved single-copy marker targets. GToTree retained sequences within 20% of the median length for each marker set and excluded genomes containing fewer than 50% of the targeted single-copy genes. It concatenated the resulting amino-acid alignments and inferred trees with FastTreeMP v2.1.11 under the JTT+CAT model, with SH-like local support based on 1,000 resamples. The *Methyloprofundus*, QPIN01/MMG2 and CAJXQU01 analyses included 88, 55 and 20 input genomes, respectively, of which 87, 53 and 20 were retained after filtering.
