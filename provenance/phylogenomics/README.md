# Phylogenomic provenance

## GTDB-Tk trees

The broad bacterial MAG phylogeny shown in Supplementary Fig. 2 was generated by GTDB-Tk using the bac120 marker framework as described in the manuscript methods. The focused Methylococcales phylogeny shown in Fig. 5 was **not independently reconstructed with GToTree**; it was pruned from that broader GTDB-Tk bac120 phylogeny.

The exact pruned Newick tree used for Fig. 5 is supplied as:

`gtdbtk/Methylococcales_pruned_gtdbtk.bac120.nwk`

The complete unpruned GTDB-Tk bac120 tree is not bundled here because it was not among the final provenance files assembled for this repository. It should be retained/deposited with the corresponding GTDB-Tk output or source-data archive if required.

## GToTree lineage-specific trees

The lineage-specific phylogenies were reconstructed with GToTree v1.7.10 using the Gammaproteobacteria HMM set (172 targets):

- Supplementary Fig. 4: *Methyloprofundus* — 88 input genomes, 87 retained.
- Supplementary Fig. 5: QPIN01/MMG2 — 55 input genomes, 53 retained.
- Supplementary Fig. 6: CAJXQU01 — 20 input genomes, 20 retained.

The original GToTree run logs are included in `gtotree/` and preserve the exact commands, software versions, filtering messages and FastTree settings. `scripts/10_phylogenomics_commands.sh` reproduces the recorded commands without inventing local paths or reference filenames beyond those recorded in the logs.
